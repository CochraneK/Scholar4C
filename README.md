# Scholar4C

用户整理的学者档案库。每位学者一个目录，存放**整理后的成品**：md 档案 + 可视化报告（自包含 HTML）。

## 三层分工

| 层 | 位置 | 内容 |
|---|---|---|
| 语料/管道层 | 本地 `D:\Software\DSH\{学者拼音}\`（如 `LiYing\`） | PDF 原件、CSV 著录、分析脚本、数据缓存 |
| **档案层（本仓库）** | `Scholar4C/{学者拼音}/` | 学者卡 + 专题 md + report.html + papers_list.csv |
| 自指层 | SecondMe `self/admired_scholars/{学者拼音}/` | 一句话画像 + 欣赏理由（关于"我"的部分） |

## 约定

- 目录名 = 学者拼音/英文姓小写（如 `li_ying/`）
- 每个学者目录必须有 `README.md` 学者卡（基本信息 + 一句话画像 + 文件索引 + 数据管道）
- **PDF 原件不入库**（体积原因；OA 论文可凭 DOI 重新下载，著录信息在 `papers_list.csv`）
- 证据纪律：事实 / 来源 / 推断 / 置信度 分层，推断标注强度（沿用 SecondMe `evidence/PROVENANCE.md` 原则）
- 数据快照注明日期；可复现的来源管道记录在学者卡里
- report.html 为单文件自包含（Chart.js 内联，无 CDN），直接浏览器打开即可
